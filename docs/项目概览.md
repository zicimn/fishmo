# fishmo 项目概览

## 1. 项目简介

`fishmo` 是一个 **galgame（美少女游戏）信息发布社区** 全栈项目，当前以 FastAPI 后端为主，前端尚处于初始化阶段。

后端核心业务：用户注册/登录、邮箱验证码、发布游戏（三名称 / 简介 / 封面 / 截图 / 标签 / 平台）、浏览量计数与 Redis 版本化缓存，以及围绕游戏的**链接分享**、**评论**、**收藏**三个扩展模块，外加**全文搜索**与**管理员审核**功能。

前端（Nuxt 3 + Vue 3 + TypeScript + Element Plus）已具备完整业务页面：首页、全部游戏（搜索/筛选/分页）、游戏详情、发布/编辑游戏、用户个人中心（资料编辑/我的游戏/评论/链接/收藏）、管理员控制台（审核/删除游戏）。

## 2. 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.11+ / FastAPI 0.133 / SQLAlchemy 2.0（异步）/ aiomysql / Pydantic v2 |
| 认证 | JWT（python-jose，HS256）+ argon2 密码哈希（passlib） |
| 缓存 | redis.asyncio（Redis 7.3，版本化缓存 + 浏览量计数） |
| 存储 | MySQL（无迁移工具，表需手动建） |
| 文件 | Cloudinary（图片统一转 WebP 后上传，PIL 处理） |
| 邮件 | Resend（验证码邮件） |
| 前端 | Nuxt 3 + Vue 3 + TypeScript + Pinia + Element Plus（`frontend/` 完整业务页面） |

## 4. 功能模块

所有接口前缀 `/api/v1`，鉴权方式为 `Authorization: Bearer <token>`（JWT）。

### user（用户）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/user/register` | 注册（需邮箱验证码） |
| POST | `/user/login` | 登录，返回 access_token |
| PUT | `/user/update` | 更新资料（用户名/邮箱/头像/简介/密码） |
| DELETE | `/user/delete` | 删除账号（存在关联作品时 400） |
| GET | `/user/` | 查看用户信息（可传 id 或凭 token） |

### email（邮箱验证码）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/email/send` | 发送 6 位验证码到邮箱（5 分钟有效，存 Redis） |

### galgame（游戏）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/galgame/` | 列表（分页，可按 category / platform / author_id / keyword 过滤，仅展示公开） |
| GET | `/galgame/rvisit` | 随机游戏（返回随机公开游戏的 id） |
| GET | `/galgame/{id}` | 详情（浏览量计数与响应缓存解耦，管理员可查看未审核游戏） |
| POST | `/galgame/add` | 发布游戏（status=False 待审核，管理员审核通过后公开） |
| PUT | `/galgame/edit` | 编辑（仅作者本人） |
| DELETE | `/galgame/delete` | 删除（仅作者本人；存在关联链接时 400） |

### link（链接分享）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/link/{game_id}` | 某游戏下公开链接列表（分页） |
| GET | `/link/user/{user_id}` | 某用户发布的全部链接（个人主页用） |
| POST | `/link/add` | 为某游戏添加链接（新增即公开） |
| PUT | `/link/review` | 编辑链接（仅作者） |
| DELETE | `/link/delete` | 删除链接（仅作者） |

### comment（评论）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/comment/{game_id}` | 某游戏下评论列表（分页） |
| GET | `/comment/user/{user_id}` | 某用户发表的全部评论 |
| POST | `/comment/add` | 发表评论（`receive_type=galgame`，`receive_id=game_id`） |
| PUT | `/comment/edit` | 编辑评论（仅作者） |
| DELETE | `/comment/delete` | 删除评论（仅作者） |

### favorite（收藏）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/favorite/add` | 收藏游戏（`gal_id` 查询参数，唯一约束防重复） |
| DELETE | `/favorite/remove` | 取消收藏 |
| GET | `/favorite/visit` | 按收藏 id 获取游戏 id |
| GET | `/favorite/list` | 当前用户收藏列表（分页） |

### search（搜索）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/search/` | 搜索游戏（支持 name/tag/company 三种搜索类型，仅公开作品） |

### admin（管理员控制台）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/control/BrowseGal` | 浏览待审核游戏列表（仅返回 ID） |
| PUT | `/api/admin/control/UpdateStatus` | 更新游戏审核状态（通过/拒绝） |
| DELETE | `/api/admin/control/DeleteGal` | 管理员删除游戏（无视作者） |

## 5. 数据模型

| 表 | 关键字段 |
| --- | --- |
| `user` | username / email（唯一索引）、password_hash、avatar、bio、status（0 禁用 1 正常）、is_admin |
| `galgame` | **name**（唯一、非空，统一名称）、cn_name / en_name / jp_name（NOT NULL）、content、company、category、cover、images、tag、views、likes、favorite、platfrom（JSON）、status（默认 False 待审核）、author_id |
| `link` | url、content、code（提取码）、category、size、status、author_id、game_id |
| `comment` | content、author_id、receive_id、receive_type（`ReceiveEnum`：0 文章 / 1 游戏） |
| `favorite` | user_id、gal_id（唯一约束 `uq_favorite_user_gal`）、created_at |

关系：`User 1—N Galgame`、`User 1—N Link`、`Galgame 1—N Link`、`User 1—N Comment`、`User 1—N Favorite`、`Galgame 1—N Favorite`。集合侧均 `lazy="raise"`（禁止隐式加载），多对一侧 `lazy="selectin"`。

共享枚举定义在 `model/enums.py`，model 与 schemas 共同引用：
- `PlatformEnum`（电脑端 / 安卓端 / Other）
- `CategoryEnum`（剧情向 / 治愈系 / 日常系 / 恋爱模拟 / 文字冒险 / RPG / 经营模拟 / 拔作 / 全年龄 / 其他）
- `ReceiveEnum`（article=0 / galgame=1）
- `SizeUnitEnum`（KB / MB / GB）
- `SearchEnum`（name / tag / company，已定义但 search.py 尚未绑定使用）

## 6. 运行方式

后端（Python 环境在仓库根 `.venv`，**必须在 `backend/app` 目录下运行**）：

```bash
cd backend/app
python main.py            # 或 .venv/Scripts/python.exe main.py
# 等价于：uvicorn main:app --reload
```

前置依赖：

- 环境变量由 `backend/app/.env` 提供（`SECRET_KEY`、`ASYNC_DATABASE_URL`、`RESEND_API_KEY`、`CLOUDINARY_*`），缺 `.env` 时 JWT 签发会失败；
- MySQL 与 Redis（localhost:6379）需启动，`user` / `galgame` / `link` / `comment` 表需手动创建（无 Alembic 迁移）；
- 图片上传依赖 Cloudinary 凭据。

前端（`frontend/`，Nuxt 3 + Vue 3 + TypeScript + Element Plus）：

```bash
cd frontend
npm install
npm run dev
```

前端页面清单：
- `/` — 首页（精选 Hero + 热门游戏 + 最新发布，深色模式微光边框，封面大图底部渐变遮罩）
- `/games` — 全部游戏（关键词搜索 + 作品/平台筛选 + 分页，URL 参数同步）
- `/galgame/:id` — 游戏详情
- `/publish` — 发布游戏
- `/user` — 登录 / 注册
- `/user/profile` — 个人中心（资料编辑 / 我的游戏 / 评论 / 链接 / 收藏）
- `/admin` — 管理控制台（审核 / 删除游戏，需管理员权限）

## 7. 关键约定与注意点

- **缓存失效**：列表/详情缓存 key 一律带业务域版本号（gal / link / comment 相互隔离）；任何增删改成功后都必须 `await update_version(对应版本 key)` 并清理相关 key，否则缓存继续服务旧数据。
- **浏览量计数**：详情接口无论缓存是否命中都用 Redis `INCR gal_views:{id}`（带 TTL），每累计 10 次用 SQL 原子自增刷入库，与响应缓存解耦。
- **图片上传**：`utils/webp.py` 全部为同步函数（PIL + Cloudinary），从 async 端点调用必须用 `run_in_threadpool` / `asyncio.to_thread` 包裹；失败返回 `None`，调用方必须判空。
- **背景图片**：前端支持用户从 `public/background/` 选择背景图，通过 `import.meta.glob` 静态发现，CSS 变量 `--fish-bg-image` 级联到 body `background` 属性，深色/浅色模式各有半透明遮罩层保证文字可读性。
- **作者即发布者**：galgame / link / comment 的删除、编辑都校验 `author_id == 当前用户`，非作者返回 403；关联数据存在时外键 `ondelete="RESTRICT"` 触发 `IntegrityError`，已捕获返回 400。
- **审核流程**：新发布游戏 `status=False`（待审核），管理员通过 `PUT /api/admin/control/UpdateStatus` 审核后公开；管理员可通过 `GET /api/v1/galgame/{id}` 绕过 `status` 限制查看未审核游戏。
- **管理员校验**：`verify_admin` 解析 JWT 中的 `is_admin` 字段，前端 `stores/auth.ts` 登录后持久化 `isAdmin` 到 localStorage，`middleware/admin.ts` 客户端守卫拦截非管理员访问 `/admin`。
- **技术约束**：FastAPI 0.133 的 `APIRouter` prefix 必须用关键字参数；Pydantic v2 用 `model_config = ConfigDict(from_attributes=True)`（禁止 `orm_mode`）；禁用 `on_event`（用 `lifespan`）。
- **前端架构**：Nuxt 3 + Pinia 状态管理 + Element Plus UI 组件库。认证 token 存于 localStorage（SSR 不可见），`layouts/default.vue` 使用 `isMounted` 门控避免水合 mismatch。类型定义（`types/`）与后端 schema 对齐，composables 封装 API 调用。
- **前端路由目录**：后端路由从 `backend/app/api/v1/` 重命名为 `backend/app/api/service/`，`main.py` 的 import 已同步更新。
